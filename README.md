### What I build
One thesis runs through everything:
- **Declare a fact once**, derive every other surface from it — no hand-synced copies.
- **The AI proposes; a deterministic verifier disposes** — nothing a model generates reaches
  a side effect without passing a mechanical check it can't talk its way around.
- **Make the mistake impossible**, don't ask the agent to be careful — fail-closed gates over prompts.
- **Append-only, evidence-first** — a claim without a resolvable citation doesn't ship.

### Selected public work
- **[operator-doctrine](https://github.com/macollins27/operator-doctrine)** — a doctrine of how to operate AI agents: a taxonomy of how they fail (confident guessing, deferral, signal-removal, drift) and the countermeasures.
- **[goalpost](https://github.com/macollins27/goalpost)** — a Claude Code plugin that stops agent goal-drift and premature "done" claims with fail-closed hooks.
- **[cc-guide](https://github.com/macollins27/cc-guide)** — an evidence-grounded Claude Code reference: a primary-sourced catalog of real agent failures and their mechanical preventions.
- **[lazyrecall](https://github.com/macollins27/lazyrecall)** — a Rust TUI (lazygit-style) for browsing, searching, and resuming Claude Code sessions.
- **[habit-daemon](https://github.com/macollins27/habit-daemon)** — an autonomous daemon that verifies habit completion against real sensor data (Concept2, Garmin, vision), never self-report.
- **[research](https://github.com/macollins27/research)** — a research-workspace harness with hook-enforced source vetting.

Much of my strongest work is private/client systems: AI control planes that let agents safely
